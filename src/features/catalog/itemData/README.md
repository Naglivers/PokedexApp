# Índice de itens

Fonte: https://github.com/PokeAPI/pokeapi/tree/2bf639e5572812a67d2b94903fdcb9d095f5aeb2/data/v2/csv

Arquivos: items.csv, item_categories.csv, item_pockets.csv, item_flags.csv e item_flag_map.csv. Os 2223 itens deste snapshot são filtrados antes da paginação; somente os detalhes dos cards visíveis são consultados na API. Preços são valores cadastrais da PokéAPI, não valores por versão ou ofertas atuais. Preço zero significa ausência de preço cadastrado, não compra gratuita.

Os JSONs contêm tuplas de ID, nome, categoria, custo, poder de Fling (null quando ausente) e IDs dos atributos. Sprites vêm do repositório PokeAPI/sprites.
